# Luinus Company Control Center

A standalone founder dashboard for the company / agents view.

## What it shows
- COO / Orchestrator
- Marketing
- Sales
- Product
- Ops
- QA / Review
- Research
- Execution queue
- Founder decisions
- Activity stream

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Notes
- This is a separate dashboard from the main Luinus app.
- UI state is seeded and stored in `localStorage`.
- Buttons are functional: refresh, advance cycle, poke agents, resolve decisions, and update queue items.
